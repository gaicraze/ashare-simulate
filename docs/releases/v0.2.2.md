# v0.2.2 发布说明

**版本**：v0.2.2
**发布日期**：2026-08-20

## 一句话概述

v0.2.2 修复交易分析中心「指数数据滞后导致选股/择时信号不完整」的根因，并为大模型分析过程补齐「自主补全数据 / 自主调用工具 / 自主创造工具」三项能力。

## 🐛 根因修复：指数数据滞后一个月

- **问题**：`indices`（沪深300）表从不参与任何增量更新，长期停在数据湖初始日期（如 2026-07-16），而 `daily`（个股日线）已增量到最新（如 2026-08-19）。所有依赖指数的工具（`get_index_trend` 月/周/日、`get_index_daily`、`get_market_regime`）因此返回陈旧数据，与个股快照/情绪数据日期自相矛盾，导致：
  - 三层择时（月线定周期、周线定方向、日线定仓位）无法对当前时点做判断；
  - 模型把陈旧指数收盘价误当最新收盘价，甚至直接输出空候选（观望），选股工具一次都没被调用。
- **修复**：
  - 新增 `updater.incremental_index_update()`，用 `sources.fetch_index_hist`（akshare 东财指数日 K）补齐 `indices` 到最新交易日，幂等可重跑。
  - `incremental_update()`（手动「增量更新」与收盘后自动调度）与 `scripts/update_daily.py` 现在同时补齐指数。
  - 数据管理页新增「补齐指数日线」按钮，状态栏展示指数数据日期与「指数滞后」提示。
  - 交易分析中心生成建议前自动 `ensure_index_fresh()`，并在盘面环境里显式标注「指数数据滞后」（`index_date` + 提示语），不再把陈旧收盘价伪装成最新价。

## 🤖 大模型分析过程增强

- **自主补全数据**：新增 `update_index_data` / `update_stock_data` 工具，分析中发现指数或个股数据滞后/缺失时，模型可主动补全后再继续。
- **自主调用工具**：选股工具调用循环从 5 轮扩到 8 轮，每轮动态刷新工具 schema，选股 `max_tokens` 调大到 8000，减少推理模型截断。
- **自主创造工具**：新增 `create_sql_tool` 工具，模型可用自然语言（或显式 SQL）创造只读查询工具，校验通过后即时注册（本会话后续轮次可用）并持久化到 `custom_tools.json`。
- 抽取统一的 SQL 工具生成助手 `backend/app/tools/generator.py`，供手动「生成工具」与分析中「自主造工具」复用。
