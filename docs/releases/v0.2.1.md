# v0.2.1 发布说明

**版本**：v0.2.1
**发布日期**：2026-08-18

## 一句话概述

v0.2.1 为一次小的修复版本：优化交易分析中心的大模型输出上下文，避免推理模型生成的操作建议被截断。

## 🔧 修复：操作建议输出被截断

- **问题**：交易分析中心生成操作建议时，推理模型（如 deepseek-v4-pro）会把大量 token 花在内部「思考（reasoning）」上，而 `max_tokens` 同时覆盖「思考 + 最终答案」，原值（8000）不足，导致最终操作建议在输出中途被截断。
- **修复**：调大 `max_tokens`：
  - 最终操作建议：`8000 → 24000`
  - 选股工具调用：`1600 → 4000`
