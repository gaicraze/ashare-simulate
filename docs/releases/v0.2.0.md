# v0.2.0 发布说明

**版本**：v0.2.0
**发布日期**：2026-08-18

## 一句话概述

v0.2.0 新增「**交易分析中心**」功能区：**选定策略 → 结合最新盘面（盘中实时）与账户资金/真实持仓 → 大模型综合研判 → 给出可执行的个股买入与持仓买卖建议**。

## ✨ 新功能：交易分析中心

### 1. 策略 + 最新盘面

- 盘中（周一至周五 09:30–11:30、13:00–15:00）自动拉取**实时指数**（沪深300 / 上证 / 深成 / 创业板）与相关个股快照。
- 非盘中或拉取失败时，自动降级为本地数据湖最新交易日数据，不影响使用。

### 2. 两种分析模式

| 模式 | 说明 |
|---|---|
| 个股买入意见（不结合仓位） | 可指定某只股票，或由大模型调用工具全市场选股，输出候选标的与买入/观望建议 |
| 结合真实仓位（买卖建议） | 针对实际持仓，结合盘面与账户，给出持有 / 加仓 / 减仓 / 止损建议 |

### 3. 账户资金 + 真实持仓（本地保存）

- 录入**本金、可用现金**，两种模式下都会结合账户资金，给出参考仓位/金额区间与整体现金/仓位管理意见。
- 录入/更新/删除**真实持仓**；数据仅保存在本地（`positions.json`、`account.json`），不会联网上传。

### 4. 补充说明（个性化要求）

- 可填写风险偏好、看好的行业/板块、资金安排、规避某类股票等。
- **优先级最高**，与策略冲突时以补充说明为准，一并作为上下文提供给模型。

### 5. 前端资产概览

- 实时计算并展示：**总资产 = 持仓市值 + 可用现金**、仓位/现金比例、相对本金盈亏。
- 持仓表显示每只持仓的现价 / 市值 / 浮盈亏。

### 6. 操作建议历史 + 独立模型路由

- 每次建议自动保存，可查看 / 导出 Markdown / 删除。
- 新增「交易分析中心」模型用途，可在「模型配置」中单独指定模型（建议用强模型）。

## 🐛 数据修复：盘中快照不再污染「收盘价」

- **问题**：数据湖近几日（08-17 / 08-18）部分个股的「收盘价」被盘中手动触发的增量更新污染——腾讯盘中快照的当前价被误当作收盘价写入 `daily.close`，属于历史数据质量问题。
- **修复**：增量更新（`backend/app/data/updater.py`）与手动更新脚本（`scripts/update_daily.py`）均增加「收盘后才落库」防护（北京时间 15:00 后）；盘中不再把盘中价写入收盘价。
- 交易分析中心的实时行情拉取改用「当日已开盘（market_open）」判断：午休/收盘后仍可拉取实时指数与个股快照用于盘中分析，但不会污染数据湖的收盘价。
